# Граница TECH.AUDIO

Ветка содержит аудиоустройства и аудио-специфичные аксессуары.

Маршрутизация:
- `AirPods`, `наушники`, `колонка`, `микрофон`, `саундбар`, `аудиоинтерфейс` -> TECH.AUDIO.
- `игровая гарнитура PS5/Xbox` -> TECH.GAMING.
- `автомагнитола`, `автомобильные колонки`, `усилитель для авто` -> TECH.CAR_ELECTRONICS_GPS.
- `телевизор`, `проектор` -> TECH.TV_HOME_THEATER.
- `зарядный кабель`, `HDMI кабель`, `power bank` -> TECH.POWER_CHARGING_CABLES.
- `вебкамера`, `клавиатура`, `мышь` -> TECH.COMPUTER_ACCESSORIES.
- `студийный монитор` -> TECH.AUDIO/STUDIO_MONITOR, не TECH.MONITORS_DISPLAYS.
