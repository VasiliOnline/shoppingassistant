# TECH_CAMERAS_DRONES_type_coverage_delta_pack_v1_1_RU

Лёгкий data-overlay patch поверх `TECH_CAMERAS_DRONES_public_category_pack_v1_0_RU`.

## Назначение
Закрыть P1-дыры по менее покрытым сегментам ветки:

- `CAMCORDER`
- `DSLR_CAMERA`
- `CAMERA_ACCESSORY`
- `BINOCULARS_TELESCOPE`
- camera/drone accessory route fixtures

## Не входит

- новые `categoryCode`
- пресеты/коллекции/SEO-полки
- полный мировой model registry
- изменение user surface / primary facets
- изменение semantics существующих attributes

## Статус

`data_overlay_patch`, готов к применению после base package v1.0. Реальные project validators запускаются после mount в registry.
