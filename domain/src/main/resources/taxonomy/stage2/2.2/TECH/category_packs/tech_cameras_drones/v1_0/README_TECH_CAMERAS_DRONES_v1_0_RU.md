# TECH.CAMERAS_DRONES public category pack v1.0 RU

Назначение: базовый production-grade data pack для public-ветки `TECH.CAMERAS_DRONES`.

Граница:
- включает камеры, дроны, объективы, опоры, стабилизаторы, свет, оптику и camera-specific accessories;
- не создаёт микрокатегории `TECH.CANON`, `TECH.DJI_DRONES`, `TECH.LENSES`, `TECH.GOPRO`;
- не включает presets/collections/SEO shelves;
- не является full model registry: head seed representative, long-tail через runtime candidates/live values.

Основной type-атрибут: `camera_type`.

Статус: static production candidate; runtime-prod только после mount + validators.
