# Boundary

TECH.CAMERAS_DRONES покрывает camera/drone/photo-video inventory, но не:
- смартфоны с хорошей камерой -> TECH.PHONES;
- webcam -> TECH.COMPUTER_ACCESSORIES;
- security camera/IP camera -> TECH.SMART_HOME_SECURITY;
- dashcam -> TECH.CAR_ELECTRONICS_GPS;
- PS5/Xbox camera -> TECH.GAMING;
- memory cards -> TECH.STORAGE_MEMORY;
- generic HDMI/USB/power cables -> TECH.POWER_CHARGING_CABLES.
