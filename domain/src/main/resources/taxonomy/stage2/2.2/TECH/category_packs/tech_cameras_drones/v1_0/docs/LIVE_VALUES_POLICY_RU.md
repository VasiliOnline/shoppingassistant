# Live values policy

Ветка содержит representative head seed, а не полный глобальный реестр моделей.
Новые камеры, дроны, объективы и accessories должны попадать в runtime_candidates/live_values.
В head seed поднимаются только частотные и стабильно распознаваемые значения после IdentityCandidateGate/AliasCollisionGate.
