# Граница TECH.COMPUTER_ACCESSORIES

`TECH.COMPUTER_ACCESSORIES` покрывает периферию и аксессуары рабочего места, но не основные устройства и не комплектующие ПК.

## Оставляем здесь

- клавиатуры
- мыши
- веб-камеры
- док-станции
- USB-хабы
- подставки
- monitor arms
- коврики
- стилусы
- адаптеры/донглы
- cooling pads
- hard shell / keyboard covers
- privacy filters
- cleaning kits

## Уводим в соседние ветки

- ноутбуки / desktop / mini pc → TECH.COMPUTERS
- мониторы → TECH.MONITORS_DISPLAYS
- CPU/GPU/RAM/motherboards → TECH.PC_COMPONENTS
- SSD/HDD/flash/memory cards → TECH.STORAGE_MEMORY
- наушники/микрофоны/колонки → TECH.AUDIO
- геймпады/консоли → TECH.GAMING
- generic chargers/cables/power banks → TECH.POWER_CHARGING_CABLES
- сумки/рюкзаки для ноутбуков → FASH.BAGS
