# No presets / collections boundary

Этот пакет не содержит discovery-пресеты, collections, shelves и SEO landing pages.

Здесь есть только category data:
- schema
- attributes
- values
- aliases
- facets
- route guards
- vision rules
- sample fixtures
- publish fixtures

Пресеты и коллекции проектируются отдельным слоем после базового покрытия веток TECH.
