# TECH.COMPUTERS scope policy

`TECH.COMPUTERS` — публичная ветка для компьютеров как устройств. Мониторы, standalone аксессуары, PC components, накопители и планшеты не входят в эту ветку.

- `ноутбук`, `macbook`, `thinkpad`, `system unit`, `mini pc`, `all-in-one`, `workstation` → `TECH.COMPUTERS`.
- `монитор 27`, `gaming monitor` → `TECH.MONITORS_DISPLAYS`.
- `клавиатура`, `мышь`, `webcam`, `dock`, `USB hub` → `TECH.COMPUTER_ACCESSORIES`.
- `RTX 4070`, `i7 12700K`, `motherboard`, `RAM module` → `TECH.PC_COMPONENTS`.
- `SSD 1TB`, `external HDD`, `NAS` → `TECH.STORAGE_MEMORY`, если нет computer context.
- `iPad`, `tablet`, `e-reader` → `TECH.TABLETS_E_READERS`.
