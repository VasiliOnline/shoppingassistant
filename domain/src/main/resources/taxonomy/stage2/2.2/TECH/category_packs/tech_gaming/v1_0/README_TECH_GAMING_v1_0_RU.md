## Scope

Covers game consoles, handheld consoles, VR headsets, game controllers, gaming keyboards, gaming mice,
gaming headsets, console accessories, physical games, and arcade equipment.

## Boundary

This package does **not** create microcategories such as `TECH.PS5`, `TECH.XBOX`, `TECH.GAMEPADS`, or `TECH.VR`.
Brand/model/platform details stay in attributes, identity/spec layers, aliases, and runtime candidates.

No presets, collections, SEO shelves, or merchandising landing pages are included.

## Source cues

Representative head seed includes stable and current platform cues from official vendor pages, but it is not a full model registry.
Long-tail titles/devices must use runtime candidates/live values.
