# TECH.GAMING boundary

Keep gaming products in TECH.GAMING only when the listing intent is gaming hardware, physical games,
console accessory, gaming input device, VR gaming headset, or arcade equipment.

Route conflicts:
- Generic keyboard/mouse/webcam/USB hub -> TECH.COMPUTER_ACCESSORIES
- Generic headphones/speakers/microphones -> TECH.AUDIO
- TV/projector/soundbar -> TECH.TV_HOME_THEATER
- GPU/CPU/RAM/motherboard -> TECH.PC_COMPONENTS
- SSD/HDD/memory cards -> TECH.STORAGE_MEMORY
- Smartphone -> TECH.PHONES
