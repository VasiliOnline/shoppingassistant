# Граница ветки TECH.MONITORS_DISPLAYS

Ветка покрывает самостоятельные мониторы/дисплеи и display-specific аксессуары.

Не покрывает:
- телевизоры и проекторы → TECH.TV_HOME_THEATER
- ноутбуки/десктопы → TECH.COMPUTERS
- графические планшеты/pen displays → TECH.TABLETS_E_READERS
- generic monitor arms/stands → TECH.COMPUTER_ACCESSORIES
- generic кабели → TECH.POWER_CHARGING_CABLES
- GPU/PC parts → TECH.PC_COMPONENTS

Важно: MONITOR_ACCESSORY оставлен для display-specific частей и аксессуаров, но не должен съедать всю ветку COMPUTER_ACCESSORIES.
