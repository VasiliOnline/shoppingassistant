# Политика данных TECH.NETWORKING

1. Не создавать TECH.ROUTERS, TECH.SWITCHES, TECH.TP_LINK, TECH.UNIFI и другие микрокатегории.
2. `networking_type` управляет UI и фасетами.
3. Brand/model seed — head-only; long-tail идёт через runtime candidates/live values.
4. PoE, port_count, Wi‑Fi standard и Ethernet speed парсятся только из title/spec/evidence.
