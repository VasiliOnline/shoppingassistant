# Route boundaries

- роутер / маршрутизатор / mesh / switch / access point / modem → TECH.NETWORKING
- NAS / сетевое хранилище → TECH.STORAGE_MEMORY
- USB hub / docking station → TECH.COMPUTER_ACCESSORIES
- security camera / video doorbell → TECH.SMART_HOME_SECURITY
- HDMI/USB/power cable, UPS, сетевой фильтр → TECH.POWER_CHARGING_CABLES
- автомобильный GPS-трекер / OBD tracker → TECH.CAR_ELECTRONICS_GPS
- PCIe network card as PC expansion card → TECH.PC_COMPONENTS unless listing intent says external adapter
