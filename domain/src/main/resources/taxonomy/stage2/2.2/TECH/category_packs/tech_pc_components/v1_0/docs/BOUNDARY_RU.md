# Boundary — TECH.PC_COMPONENTS

Included:
- CPU, GPU, motherboards, RAM modules, PSUs, PC cases, CPU coolers, case fans, thermal paste, capture cards, sound cards, network cards, expansion cards.

Excluded and routed out:
- SSD/HDD/USB flash/memory cards → TECH.STORAGE_MEMORY
- keyboards/mice/webcams/USB hubs/docking stations/laptop stands → TECH.COMPUTER_ACCESSORIES
- laptops/desktops/mini PCs/all-in-one systems → TECH.COMPUTERS
- monitors → TECH.MONITORS_DISPLAYS
- charging cables, UPS, power banks, surge protectors → TECH.POWER_CHARGING_CABLES
- headphones/speakers/microphones/audio interfaces → TECH.AUDIO

No presets, collections or SEO landing pages are part of this base package.
