# Source notes — TECH.PC_COMPONENTS v1.0

This package is a base catalog data pack, not a full current global product registry.

Head model seed includes representative CPU/GPU/component examples used for identity/routing smoke tests.
Current-generation cues used while composing the seed:
- NVIDIA official GeForce RTX 50 Series page lists RTX 5090, 5080, 5070 Ti, 5070, 5060 Ti, 5060 and 5050.
- AMD Ryzen desktop page highlights Ryzen 9000 Series and Ryzen 9950X3D references.
- Intel Core Ultra page documents Intel Core Ultra Series processors as current Intel processor family.
- AMD Radeon desktop graphics page references AMD Radeon RX 9000 Series and RX 9070 XT partner cards.

Do not treat component_head_seed as exhaustive. Long-tail product models should enter via runtime candidates/live values.
