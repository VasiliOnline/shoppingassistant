# Compatibility evidence policy

Model-specific аксессуары требуют доказательства совместимости. Приоритет evidence:

1. Barcode/vendor page/source URL.
2. OCR упаковки с явной моделью.
3. Явное название: “для iPhone 15 Pro”.
4. Явное описание.
5. Visual-only — слабое evidence; нельзя делать exact model resolution.

Камера/вырез/форма чехла не являются достаточным доказательством exact model.
