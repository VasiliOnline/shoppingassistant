# Граница TECH.PHONE_ACCESSORIES

Ветка закрывает только аксессуары телефона. Устройство без accessory noun уходит в `TECH.PHONES`. Generic кабели/зарядки без phone/mobile/model context уходят в `TECH.POWER_CHARGING_CABLES`. Ремешки для Apple Watch уходят в `TECH.WEARABLES`, чехлы AirPods — в `TECH.AUDIO`, чехлы iPad — в `TECH.TABLETS_E_READERS`, чехлы ноутбуков — в `TECH.COMPUTER_ACCESSORIES`.

Брендовые/модельные пользовательские полки не входят в этот пакет. Они будут отдельной discovery/presets темой после базового покрытия веток.
