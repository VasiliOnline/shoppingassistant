# TECH.PHONES route policy

Positive route:
- full phone device listings
- smartphone, feature phone, foldable phone, rugged phone, retro phone, satellite phone

Negative route:
- cases, screen protectors, batteries, displays, camera glass, SIM tools -> TECH.PHONE_ACCESSORIES
- chargers, cables, power banks -> TECH.POWER_CHARGING_CABLES / PHONE_ACCESSORIES according to route policy
- AirPods/headphones/headsets -> TECH.AUDIO
- smart watches/bands -> TECH.WEARABLES
- tablets/iPad -> TECH.TABLETS_E_READERS
- computers/MacBook/laptop -> TECH.COMPUTERS

Rule: phrase “for / для + model” is a strong accessory signal unless the listing explicitly sells the full phone.
