# Sources and evidence policy

This package is a catalog pack, not a live product database. `model_head_seed` is a head seed for routing/search/identity candidate generation. It is not a complete or permanently current registry.

Official source pointers used for head seed sanity checks:

- Apple iPhone Compare: https://www.apple.com/iphone/compare/
- Samsung Galaxy S official category page: https://www.samsung.com/us/mobile/phones/galaxy-s/
- Google Store Phones: https://store.google.com/category/phones
- Xiaomi Global phones product list: https://www.mi.com/global/product-list/phone/

Runtime rule: new/changed models enter through runtime candidates/live values and must pass IdentityCandidateGate + AliasCollisionGate before promotion.
