# Delta policy

Этот patch закрывает только data-gap текущей ветки. Он не является новым category pack.

Основное правило маршрутизации:

- `сетевой фильтр`, `удлинитель`, `power strip` → `TECH.POWER_CHARGING_CABLES`.
- `сетевой адаптер Wi-Fi/Ethernet/RJ45`, `LAN кабель`, `патч-корд` → `TECH.NETWORKING`.
- `ATX PSU / блок питания ПК` → `TECH.PC_COMPONENTS`.
- `USB hub / docking station` → `TECH.COMPUTER_ACCESSORIES`.
