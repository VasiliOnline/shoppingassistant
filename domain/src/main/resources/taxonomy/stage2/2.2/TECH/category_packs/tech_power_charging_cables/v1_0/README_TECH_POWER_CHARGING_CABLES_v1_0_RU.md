# TECH.POWER_CHARGING_CABLES public category pack v1.0 RU

Base production data pack for `TECH.POWER_CHARGING_CABLES`.

Scope: wall chargers, wireless chargers, car chargers, USB/HDMI/audio-video cables, adapters, power banks, portable power stations, UPS, batteries, surge protectors and cable management.

Not included: presets, collections, SEO landing pages, microcategories, full global model registry.

Important route boundary:
- Phone cases/screen protectors -> TECH.PHONE_ACCESSORIES
- USB hubs/docks -> TECH.COMPUTER_ACCESSORIES
- RJ45/patch panels -> TECH.NETWORKING
- PC PSUs -> TECH.PC_COMPONENTS
- Generic power/charging/cables -> TECH.POWER_CHARGING_CABLES

Status: static production candidate; runtime validators must run after mount.
