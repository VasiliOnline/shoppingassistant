# Граница TECH.PRINTERS_SCANNERS

Ветка покрывает печать/сканирование и расходники для печати.

Входит:
- принтеры
- МФУ
- сканеры
- принтеры этикеток
- струйные картриджи
- тонер-картриджи
- аксессуары для принтеров/сканеров

Не входит:
- 3D-принтеры и филамент
- кассовые аппараты и POS-терминалы
- generic USB/HDMI/power cables
- роутеры и сетевое оборудование
- фотоаппараты и камеры
