# Граница TECH.SMART_HOME_SECURITY

Попадает: smart-home automation and household security devices.
Не попадает: generic Bluetooth speakers -> TECH.AUDIO; webcams -> TECH.COMPUTER_ACCESSORIES; dash cams -> TECH.CAR_ELECTRONICS_GPS; routers -> TECH.NETWORKING; action/photo cameras/drones -> TECH.CAMERAS_DRONES.
