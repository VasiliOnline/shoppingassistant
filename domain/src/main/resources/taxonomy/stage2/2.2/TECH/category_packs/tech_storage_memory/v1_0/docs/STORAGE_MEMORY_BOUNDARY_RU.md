# Граница TECH.STORAGE_MEMORY

`TECH.STORAGE_MEMORY` покрывает накопители, карты памяти, кардридеры, NAS и аксессуары для хранения данных.

Не входит:
- RAM/DDR memory modules → TECH.PC_COMPONENTS
- GPU VRAM → TECH.PC_COMPONENTS
- USB hubs → TECH.COMPUTER_ACCESSORIES
- Power banks → TECH.POWER_CHARGING_CABLES
- SIM cards/eSIM → TECH.PHONE_ACCESSORIES / telecom policy
- Cameras/consoles/laptops themselves → their public categoryCode

Ключевое правило: storage/memory в названии не означает автоматический route в `TECH.STORAGE_MEMORY`.
