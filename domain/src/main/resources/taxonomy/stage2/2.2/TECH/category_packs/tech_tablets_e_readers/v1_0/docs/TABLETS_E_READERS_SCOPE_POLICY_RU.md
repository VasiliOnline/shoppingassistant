# Scope policy

`TECH.TABLETS_E_READERS` покрывает планшеты, e-readers, графические планшеты и минимальные tablet-specific docks/stands.

Не включать:
- телефоны и смартфоны → TECH.PHONES
- ноутбуки / Chromebook как laptop → TECH.COMPUTERS
- мониторы → TECH.MONITORS_DISPLAYS
- общие клавиатуры/мыши/webcam/hubs для ПК → TECH.COMPUTER_ACCESSORIES
- чехлы/стёкла для iPhone → TECH.PHONE_ACCESSORIES
- игрушечные планшеты → KIDS.TOYS_OR_OTHER
- бумажные книги → BOOKS_OR_MEDIA
