# TECH_TV_HOME_THEATER_public_category_pack_v1_0_RU

Production-grade base public category pack для `TECH.TV_HOME_THEATER`.

## Scope

Ветка покрывает телевизоры, проекторы, стриминговые устройства, TV boxes, комплекты домашнего кинотеатра, AV-ресиверы, DVD/Blu-ray players, set-top boxes, пульты, TV mounts и projector screens.

## Boundaries

Не содержит пресеты, коллекции, SEO-полки и микрокатегории. Не создаёт `TECH.TV`, `TECH.PROJECTORS`, `TECH.APPLE_TV`, `TECH.DENON_RECEIVERS`.

## Runtime status

Static data-covered candidate. Реальный prod release требует mount + project validators.
