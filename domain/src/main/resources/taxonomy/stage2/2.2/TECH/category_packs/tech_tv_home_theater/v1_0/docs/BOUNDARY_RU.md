# Граница TECH.TV_HOME_THEATER

Внутри ветки: TV, projectors, streaming devices, TV boxes, home theater systems, AV receivers, disc players, set-top boxes, remotes, TV mounts, projector screens.

Снаружи ветки:
- Soundbars, headphones, microphones -> TECH.AUDIO
- Computer monitors -> TECH.MONITORS_DISPLAYS
- Game consoles -> TECH.GAMING
- HDMI/USB/power cables -> TECH.POWER_CHARGING_CABLES
- Monitor arms, docks, USB hubs -> TECH.COMPUTER_ACCESSORIES
