# TECH.WEARABLES public category pack v1.0 RU

Production-grade base data pack for `TECH.WEARABLES`.

## Scope
- Smartwatches
- Fitness trackers
- Smart rings
- AR / smart glasses
- Wearable accessories
- Watch bands / straps for smart devices

## Boundary
This is not a preset/collection/merchandising pack and does not create microcategories such as `TECH.APPLE_WATCH`, `TECH.GALAXY_WATCH`, `TECH.SMART_RINGS` or `TECH.WATCH_BANDS`.

## Runtime stance
- Head model seed is representative, not a full global model registry.
- Long-tail models must go through runtime candidates/live values.
- Exact model must not be guessed from image alone.
- Ordinary mechanical/fashion watches route to `FASH.ACCESSORIES`.
- Smartwatch bands and smart wearable accessories stay in `TECH.WEARABLES` with compatibility fields.
