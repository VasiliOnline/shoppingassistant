# Boundary: TECH.WEARABLES

Ветка покрывает носимую электронику. Обычные механические/модные часы и ювелирные кольца не входят в TECH.WEARABLES.

Ключевые routing rules:
- Apple Watch / Galaxy Watch / Garmin / Fitbit -> TECH.WEARABLES
- Ремешок Apple Watch / Garmin QuickFit -> TECH.WEARABLES + WATCH_BAND
- Обычные часы Seiko / Orient без smart evidence -> FASH.ACCESSORIES
- AirPods / наушники -> TECH.AUDIO
- iPhone / смартфон -> TECH.PHONES
